# Changelog

## 0.1.0 — 2026-11-05

Initial development package, not an empirically validated research system.

- Five fixed stages with scientist-in-the-loop interaction and explicit confirmation.
- Literature discovery and paper workflow reconstruction within Stage 2.
- Cross-domain profiles, resource feasibility checks and agile amendment protocol.
- Living specification, evidence/decision records and versioned baseline templates.
- Optional local helper for scoped approval receipts, consistency checks and snapshots.
- Cross-platform local installer, deterministic ZIP builder, package lint and unit tests.
- English/Korean documentation, teaching example and behavioral evaluation scenarios.
- Publication helper with dry-run default and explicit authenticated execution.
